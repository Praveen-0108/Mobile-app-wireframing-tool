Mobile App Wireframing
Project Overview

This project focuses on designing low-fidelity wireframes for a mobile application to improve user experience and application structure before development. The wireframes help visualize screen layouts, navigation flow, and user interactions in a simple and organized manner.

The project includes user research, user personas, user flow creation, and wireframe design using UI/UX design tools such as Figma or Adobe XD.

Objectives
Understand user needs through basic research
Create user personas and user flows
Design low-fidelity mobile app wireframes
Improve app usability and navigation
Document the design thinking process
Features
User-friendly mobile app layout
Screen navigation planning
Login and registration wireframes
Home dashboard design
Profile and settings screen layout
Interactive user flow structure
Tools & Technologies
Figma

UI/UX Design Principles
Design Thinking Methodology
Design Process
1. User Research

Collected basic information about target users and their requirements.

2. User Persona Creation

Created sample user personas to understand user behavior and expectations.

3. User Flow Design

Planned how users move through different screens of the application.

4. Low-Fidelity Wireframing

Designed basic wireframes representing the structure and functionality of the app.

5. Documentation

Documented the complete design thinking process and project workflow.
